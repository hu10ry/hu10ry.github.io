# LARGE PORTIONS OF THIS WEBSITE WERE GENERATED WITH AI
I am not claiming that I created any of these ports unless otherwise specified, I wanted a place where I could play web games, and have the saves backed up to disk - that's what this website is supposed to do.

## Game list

The homepage loads games from `games.json`. Each entry needs a `name` and `url`; `image_url` can be set to an image URL to display a cover image, and `note` is optional. Set `interpolate` to `false` to render an image without smoothing (useful for pixel art); it defaults to `true`.
